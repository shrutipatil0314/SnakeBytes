# Tkinter Calculator

This is my calculator app for the Module 10 Tkinter assignment. It opens a small window where you can click buttons to do basic maths, kind of like the calculator on a phone.

What it can do

- Add, subtract, multiply and divide
- Show what you type and the answer in the box at the top
- Clear everything with the `clear` button
- Show "Cannot divide by 0" if you try to divide by zero, and "Error" if the expression doesn't make sense (like `5+` with nothing after it)

How to run it

You need Python 3 installed. Tkinter comes with it, so there is nothing else to download.
Open a terminal in this folder and type:

```
python tkinter_calculator.py
```

On Mac or Linux you might need `python3` instead of `python`.
The box at the top is read-only, so you can't type into it from the keyboard. You have to use the buttons.
